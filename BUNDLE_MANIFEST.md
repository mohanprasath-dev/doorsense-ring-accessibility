# Bundle Manifest

This ZIP contains planning and execution documents for building DoorSense with Google Antigravity.

The recommended repository is `doorsense-ring-accessibility`. Its description is: “Accessibility-first Ring companion that turns ambiguous doorbell and camera events into clear, calm, visual-first guidance.”

The technology plan is completely free to run locally: TypeScript, Node.js, React, Vite, Fastify, Zod, SQLite, Vitest, Playwright, axe-core, GitHub, and the Ring developer integration available to the participant. Cloudflare Pages, Workers, and D1 are optional free-tier providers for preview or hosting. Supabase is intentionally excluded.

This is a documentation and planning kit, not the application source code itself. The Ring runtime integration still needs to be implemented, tested with the supported Ring simulator/API/device path, and shown in the final demo.
