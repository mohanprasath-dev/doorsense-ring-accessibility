# Release Checklist

## Product

- [ ] Ring runtime path works.
- [ ] Three scenarios work from a clean checkout.
- [ ] Ambiguous events remain unclassified.
- [ ] No unsafe automation or identity claims.
- [ ] Accessibility scan has no critical violations.

## Repository

- [ ] `README.md` has setup and run steps.
- [ ] `LICENSE` is present if public.
- [ ] `.env.example` contains placeholders only.
- [ ] No secrets, tokens, private recordings, or raw unnecessary personal data.
- [ ] Tests and lint pass.
- [ ] Fixtures are labeled test-only.

## Demo

- [ ] Ring source is visible early.
- [ ] Video is public, English, and under three minutes.
- [ ] Captions or narration are clear.
- [ ] No copyrighted music or unlicensed footage.

## Devpost

- [ ] Project description completed.
- [ ] Ring selected as primary track.
- [ ] Accessibility emphasized.
- [ ] AWS Builder omitted unless actually implemented.
- [ ] Product feedback completed for each relevant tool.
- [ ] Existing-project disclosure completed if needed.
- [ ] Optional feature requests are specific.
- [ ] Optional friction log is reproducible.
